Features

One bot, every modality

Each capability is a pluggable model behind a unified pipeline — adding a new Replicate model is configuration, not code.

🎨

Image generation

Text-to-image, image-to-image and inpainting with Flux, DALL·E 3 and Stable Diffusion. Prompt optimization and negative prompts built in.

🎬

Video generation

Create clips from prompts or animate a still image — Kling, Wan and HunyuanVideo, delivered straight to the chat when rendering finishes.

🎙️

Audio & voice

Music generation, voice cloning and text-to-speech through the same credit and delivery pipeline as images and video.

💬

LLM chat with memory

Persistent chat history with periodic summarization. Rapid bursts of messages are batched into one coherent reply instead of five fragmented ones.

📱

Telegram Mini App

A React web app inside Telegram: browse models, buy credit packages and change settings. Calls a Flask API with signed init_data.

👥

Group mode

Add the bot to a group: Gemini-powered chat with personality, per-group language, group-aware credits and a one-time AI-generated welcome DM.

How it works

From message to media

Clean architecture under the hood: presentation, application and infrastructure layers stay separate, so backends can be swapped without touching handlers.

01 — Telegram

Message arrives

aiogram handlers route by context: group chat, menu, payments or generation.

02 — Application

GenerationService

Validates input, checks and charges credits, picks the model and routes the request.

03 — Infrastructure

UnifiedAIClient

Talks to Replicate, OpenAI or Gemini behind one interface. Webhooks handle async renders.

04 — Delivery

Result in chat

Media is sent back to the user; state and transactions live in Neon PostgreSQL.

Payments & reach

Stars in, four languages out

⭐ Telegram Stars (XTR)

Native in-chat payments — no Stripe, no external provider, no checkout redirect. Users buy credit packages in the shop or the Mini App; every transaction is recorded in the database.

🌍 Full i18n

Every menu, prompt and error message is localized. Group admins set the language per group.

Research roadmap

From generation hub to autonomous agent

Today you pick a model and send a prompt. The next evolution — in the spirit of agent frameworks like OpenClaw — is a bot that plans, acts and remembers on its own. Each phase is grounded in the research that defines it.

PHASE 01planned

Autonomous tool selection

The bot reasons about which model fits a request — no menu navigation, just intent. A reasoning + acting loop picks image, video or audio backends by itself.

ReAct — Yao et al., 2022 Toolformer — Schick et al., 2023
PHASE 02planned

Multi-step planning

"Make a logo, animate it, add a jingle" becomes one request: the bot decomposes the goal and pipes intermediate results between models automatically.

Tree of Thoughts — Yao et al., 2023 Plan-and-Solve — Wang et al., 2023
PHASE 03foundation exists

Long-term memory

Chat sessions and summarization already persist — next: hierarchical memory with user preferences, past generations and style profiles across sessions.

MemGPT — Packer et al., 2023 Generative Agents — Park et al., 2023
PHASE 04planned

Self-reflection & skill learning

Failed generations become training signal: the bot retries with improved prompts and grows a library of proven prompt and parameter "skills".

Reflexion — Shinn et al., 2023 Voyager — Wang et al., 2023
PHASE 05schema sync exists

Open tool ecosystem

Replicate model schemas auto-discovered as callable tools, and AZAMAT itself exposed via the Model Context Protocol — usable by external agents.

ToolLLM — Qin et al., 2023 Gorilla — Patil et al., 2023
PHASE 06planned

Evaluation & guardrails

Benchmarked agent decisions, hard credit budgets on autonomous actions and confirmation thresholds — autonomy that never surprises the user's wallet.

AgentBench — Liu et al., 2023 Agent survey — Wang et al., 2023

Quick start

Running in five minutes

Python 3.10+, a PostgreSQL database (a free Neon instance works) and two API tokens are all you need.

# clone & install
$ git clone https://github.com/alivsch-ai-code/flux-bot-azamat.git
$ cd flux-bot-azamat
$ pip install -r requirements.txt

# configure (.env)
$ cp .env.example .env

# run
$ python main.py
